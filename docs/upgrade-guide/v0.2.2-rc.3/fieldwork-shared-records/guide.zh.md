# Fieldwork 共享记录

[English](guide.md) | 中文

## 变更

Fieldwork 私有记录改用架构版本 2，增加共享田块、来源快照和玉米规划版本。存储路径继续使用 `$DSH_HOME/fieldwork-native/records.v1.json`；文件名不再代表当前架构版本。

内置入门流程将 `$DSH_HOME/fieldwork/onboarding.json` 中的田块修正和笔记导入共享记录。供应商缓存文件保留原位置。独立开发入门插件仍使用自己的文件。

真实数据模式不再展示未经验证的农艺风险分类或水分、土壤流失及肥料成本估算。演示仍明确使用虚构数据。

## 迁移

1. 停止使用同一数据目录的其他 Fieldwork 进程。每个记录文件仅运行一个 Host。
2. 正常启动。有效 v1 文件先保留为 `records.v1.json.v1.backup`，下次成功写入时提交 v2 状态。保留既有农场背景、试验、摘要和比较，以及原入门文件。
3. 打开“我的农场”或“玉米规划”，核对田块笔记和年度作物修正。“来源库”和“玉米规划”为新增原生面板。
4. 若出现数据损坏或备份冲突，先保留两个文件并解决冲突再启动。应用会报错，不会重置记录。

旧代码无法读取 v2。回退时先停止 Host，保留 v2 文件与 `originals` 目录，再恢复 v1 备份。旧版本无法使用新来源、共享田块修改和玉米规划版本；保留 v2 副本以便再次升级。
