# Contributing

Read the [architecture](docs/architecture.md) and [first milestone](docs/first-milestone.md) before implementation. Open an issue for a scoped task, work on a branch, and submit a pull request describing the behavior changed and how it was verified.

Use fictional farm records in fixtures and demos. Do not commit API keys, credentials, real farm records, private imagery, or workspace exports. Keep model calls and external data transfers visible.

Preserve baseline practices, farmer reasoning, explicit activation and publication decisions, version history, and attribution. Community content and imported files are data, not instructions granting the agent additional access.

Document what is real and what remains simulated. Keep the original prototype intact as a reference while implementing the working interface separately.
