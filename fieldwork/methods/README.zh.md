# 田间学习方法

[English](README.md) | 中文

原生 Fieldwork 插件连接方法发现、每周数据检查、巡田、玉米比较及已审核的学习记录。每种方法包含可读的 `method.json` 发现卡及 `SKILL.md` 说明。计算由已安装代码执行；编辑方法文件不会安装或执行脚本。

## 使用流程

在 Harness 侧栏打开 **Field learning**。审核后，**Try the learning example** 创建明确标记为虚构的田块及模拟监测。运行检查、调查观察、保存巡田笔记、起草比较、审核测量及布局，再记录结果和农户决定。后续比较关联此前记录，不改写原记录。

使用自己的田块时，先在 Corn planning 添加田块，通过 Source library 导入支持文件，支持 JSON 和 GeoJSON 原件。可粘贴 Polygon 或选择导入的 Polygon、Feature 或单要素集合来启用监测。启用前确认真实边界及外部访问，不根据农场名称猜测位置。

发现卡说明问题、工作量、前提、输出及局限。内置方法为[监测田块](watch-field/SKILL.md)、[调查模式](scout-pattern/SKILL.md)及[比较玉米做法](corn-strip-trial/SKILL.md)，可独立使用。本实现不包括社区代码安装、任意方法执行或自动发布。

## 监测语义

启用操作授权所配置的数据可用性检查及本地结果文件。监测在所选运行环境中每经过七天执行一次，独立于模型会话。在 Field learning 管理监测；Harness 的 Automation tasks 页面继续管理模型提示。手动检查保留下一次尚未到期的计划。暂停会取消活动检查并保留历史；继续会使检查到期。电脑关闭时不执行检查；重启标记中断记录，并可补做一次到期检查，不重放每个错过的周次。

每次尝试记录运行中、新可用观察、无新数据、无可用新影像、失败或中断。缺失影像不会变成作物健康结果或图表中的零。默认回溯窗口为 30 天，可发现该窗口内延迟到达的产品。每次搜索最多 50 个目录条目，处理三个新场景；有限批次在回执中明确说明。同一场景版本不重复处理。供应商失败保留此前观察。存储提交失败会停止监测并显示持续错误，直到检查并重启。

实时检查使用公开 Earth Search `sentinel-2-c1-l2a` 集合及公开 COG 文件。实现使用原生红光及近红外像素、Collection 1 缩放及偏移元数据、最近原生 SCL 类别 4 和 5，以及多边形内像素中心。排除云、阴影、水、雪、不确定、缺失及非法反射率像素。部分瓦片的缺失像素降低覆盖率。资格由所选有效比例及原生像素数确定，默认分别为 0.6 和 16。128 像素显示网格仅用于可视化，均值使用裁剪内所有有效原生像素。仅支持 UTM 场景、单一多边形环和每波段最多 262144 个裁剪像素。不支持的输入或元数据会产生可见失败记录。

NDVI 为观察背景。作物阶段及田间条件影响比较；窄试验条带可能无法分辨。原因调查需要巡田。试验摘要只计算配对区组算术均值，明确产量单位及缺失区组，不执行显著性检验、因果归因、肥料建议、产量预测或利润计算。实际设计及水分校正测量需要当地审核。仅含标题行的收获 CSV 可保存无定论学习记录，均值标为不可用，不虚构零值。

## 文件及配置

源码配置将工作空间置于 `$DSH_HOME/fieldwork-workspace/learning`。`index.json` 拥有记录索引。`methods/<id>/v1` 包含私有清单及说明副本，启用时保存包快照及内容哈希。`artifacts/<sha256>` 保留原始边界内容、目录元数据、CSV 原始裁剪像素及质量类别、NDVI JSON、检查回执、巡田 Markdown、试验协议、收获模板和结果及学习摘要。下载需所有者会话并验证哈希。修改已保存文件会被检测到；改变记录应创建已审核版本。私有方法修改用于后续启用，保留此前快照。

`fieldwork-learning` Cordis 插件接受 `root`（必填）、`pollSeconds`（30）、`checkTimeoutSeconds`（90）及 `scenesPerCheck`（3）。轮询寻找到期任务，不改变七天计划。销毁完成前，会等待供应商、取消、已接纳工作、计时器及存储提交结束。每个工作空间使用一个 Host。备份农场时保留此目录；它补充现有记录而不重写它们。

## 验证

`pnpm --filter @fieldwork/plugins test` 覆盖调度、无数据区别、取消、重启恢复、文件、证据关联及描述性结果。`node --test fieldwork/ui/learning.browser.test.mjs` 验证原生农户流程并捕获忽略的截图。`FIELDWORK_SATELLITE_TEST=1 node --import tsx/esm --test fieldwork/plugins/satellite.live.test.ts` 检查公开参考影像，不需凭据或模型，文件置于 `.artifacts/live-satellite`。

2026 年 7 月 30 日的公开参考场景产生 11705 个有效多边形像素及平均 NDVI 0.36178865076947253。独立 rasterio/GDAL 计算的像素数相同，均值在 1e-10 内一致。[应用结果](watch-field/qualification/reference-result.json)和[独立结果](watch-field/qualification/independent-result.json)记录这项软件检查。它不是用户农场观察，也不代表跨场景和地区的广泛科学验证。

## 选择处理前先调查

[调查重复出现的低产区域](historical-yield/SKILL.md)保存田块、可选的问题季节、已知的当前做法、各来源的季节及作物、笔记和带可选负责人及截止日期的本地任务。缺少报价、目标、当前作物或几何不会阻止保存调查。[Beltsville 公开示例](../examples/beltsville/README.zh.md)提供经过明确审核的起点，不替换农户做法。

以分页表格、PDF 页面文本或原始 PNG/JPEG 地图查看关联证据。选择表格单元格以获取精确引用。保存质量检查前明确选择 X、Y、产量列、单位和坐标系标签。缺失值不变成零。点图保持坐标纵横比例；大图显示抽样点，汇总使用所有有效行。分析文件保留原始来源哈希及描述性局限，不自动对齐跨季数据或计算持续性。

每次调查保存固定可读的 JSON/Markdown 快照和方法包。编辑检查打开表单时记录的版本，拒绝过期编辑。分析及本地任务修改留在同一调查中，后续试验草稿保留调查身份和所选证据。Experiments 显示这些共享比较及较早的简易试验记录。负责人和日期只是本地记录，不发送邀请或通知。

学习索引使用第 2 版。打开第 1 版索引时，将原始字节保留至 `index.json.v1.backup`，读取此前的监测、巡田及试验记录，并将调查默认为空。下次成功写入提交第 2 版。备份冲突时阻止打开而不覆盖。工作空间应使用当前运行环境；旧读取器拒绝第 2 版。新的可选来源元数据记录田块、季节和图片媒体类型，不改变原件字节。
