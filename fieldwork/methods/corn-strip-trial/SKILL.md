# Compare one change with the farmer's corn practice

This guided planning method is informed by published Nebraska Extension protocols. Fieldwork's schematic is not a validated machinery prescription or an exact reproduction of a university protocol. Read the original guidance and review local design needs.

1. Start from the farmer's question, current practice and reasons, constraints, equipment, and available measurements. Read their worksheet and linked scouting note. Pin the source files and any accepted corn seed-budget revision.
2. Change one factor. State the baseline and alternative explicitly. Decide what would make the change useful before starting: yield, input cost, workload, risk, or another measured outcome. Yield difference alone does not establish profit.
3. Choose exploratory comparison or randomized blocks. Select replication for field variability and the effect worth detecting, with an adviser where needed. Two blocks is a software minimum, not a recommended design. A single comparison remains exploratory. Respect equipment width, buffers, headlands, soil variation, and the practical harvest plan. The generated layout is a relative schematic only; confirm actual placement separately.
4. Review the draft and measurements before starting tracking. Save the method snapshot, random treatment order, source hashes, and field context. Material changes need a new draft; record deviations in the outcome notes.
5. Measure the experimental unit, not individual satellite pixels as independent replications. Enter matched baseline and alternative yields for each block in consistent kg/ha or t/ha, using comparable moisture-corrected measurements. Retain original harvest records. Missing blocks remain visible.
6. The installed calculation produces block differences and arithmetic means only. It does not perform a significance test, establish causality, or calculate profit. Record unusual events and confounders. No difference and inconclusive results are useful outcomes.
7. Save a reviewed interpretation and the farmer's decision: retain, repeat, modify, or cautiously expand. Link the next trial to the earlier record rather than overwriting it. Community sharing remains a separately reviewed action.

Sources: https://cropwatch.unl.edu/farm-research-tests and https://cropwatch.unl.edu/2016/10-steps-farm-research-success/ .
