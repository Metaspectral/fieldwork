# Investigate a field pattern

Use after an imagery observation, a farmer's concern, or an existing field note. Read the current practice and its reason first. A satellite pattern is a reason to investigate, not a diagnosis.

1. Identify one question the farmer wants to answer. Read the originating check and its quality if one is linked.
2. Agree a practical visit or measurement. Compare the area of concern with an appropriate reference area. Record dates, crop stage, stand counts, soil conditions, recent operations, photographs, and weather context when available. Preserve the farmer's own document format; Markdown is the built-in note editor, and other originals can be cataloged in Source library.
3. Separate observations from possible explanations and missing information. Ask which explanations remain plausible and what measurement could distinguish them. Do not label a guessed nutrient deficiency, pest, or water problem as confirmed.
4. Save a farmer-reviewed note referencing the field, source observation, and supporting files. The note is retained as a Markdown file with a hash and the selected method snapshot.
5. Offer three valid next steps: keep observing, seek local advice or measurements, or design a manageable comparison for a future operation. Keeping the current practice is a valid decision.

Sources: https://www.innovativefarmers.org/about-us/what-is-a-field-lab and https://www.sare.org/publications/how-to-conduct-research-on-your-farm-or-ranch/introduction-6/what-is-on-farm-research/ .
