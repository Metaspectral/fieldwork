# Fieldwork

[English](README.md) | 中文

由农户自主掌控的工作空间，用于保留现有做法、探索替代方案，并从试验中学习。

Fieldwork 从农户当前的工作方式及其原因出发。插件可以记录这些做法，补充天气或影像信息，比较成本，或帮助测试可控的改变。经验、观察和研究保留各自的来源；农户决定采用和分享什么。

## 规划架构

定制的 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) 运行时部署在农户电脑上。浏览器界面让农户通过电脑或手机访问同一个工作空间。试验在运行时执行，记录保存在那里。

可选服务提供远程连接、社区发布，以及面向偏好云计算用户的托管运行。这些是独立的选择。分享只发布选定的摘要，不发布私人工作空间。

本地执行不代表使用本地模型：云模型会收到发送给它的上下文。工作流必须明确显示外部数据使用情况。

## 探索原型

在浏览器中打开 `prototype/index.html`。该文件独立运行，无需 API 密钥或构建步骤。不同浏览器对本地文件的行为可能有所差异。

助手、社区、天气和卫星功能均为模拟。演示状态保存在浏览器 localStorage 中，没有账户或真实的受众访问控制。请使用虚构记录。工作空间导出文件包含私人演示状态。

保留暖纸色、炭灰色和陶土色的视觉方向、紧凑界面，以及五个页签：Today、Community、Plug-ins、Experiments 和 My farm。

## 第一个里程碑

保存农户当前的种子采购做法，通过确定性插件比较另一份报价，并通过真实智能体保存结果。在同一网络中的手机上打开同一工作空间，确认重新连接后记录仍然存在。

后续里程碑增加远程访问、可复现的 Sentinel-2 工作流、选择性社区发布及可选的托管运行。
