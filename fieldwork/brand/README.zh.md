# Fieldwork 品牌

[English](README.md) | 中文

Fieldwork 是农户自主拥有的工作空间，用于保留基线、测试可控的改变并保存证据。

- 名称：**Fieldwork**。
- 标语：**Your farm. Your findings.**（你的农场，你的发现。）
- 标志：[分层田地](mark.svg)，复用 Harness 分层图标，置于绿色方块中。
- 配色：田野绿 `#28634C`、浅绿 `#EDF4EF` 及米白 `#F6F8ED`。深色页面在 `#1C2D24` 上使用 `#9ACBAD` 作为易读的强调色。
- 字体：原生 Harness 应用字体，名称使用中等字重的文本字标。

原生 UI 插件拥有侧栏字标及标志、页面强调色和标语。`pnpm run fieldwork:build` 设置 Fieldwork 浏览器标题，并将标志复制到生成的浏览器网站图标。源码叠加配置禁用上游装饰性主页品牌；Harness 布局和控件保持原生。

这是黑客松的初始品牌。保持标志简洁、对比度易读，并标明演示数据。标志复用 MIT 许可的 DeepSeek Harness 图形；分发时保留仓库许可及署名。参见[实际应用截图](../screenshots/README.zh.md)。
