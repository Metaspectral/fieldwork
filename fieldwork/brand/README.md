# Fieldwork identity

English | [中文](README.zh.md)

Fieldwork is a farmer-owned workspace for keeping a baseline, testing a manageable change, and retaining the evidence.

- Name: **Fieldwork**.
- Tagline: **Your farm. Your findings.**
- Mark: [layered field](mark.svg), reusing the Harness layers icon in a green square.
- Palette: field green `#28634C`, pale green `#EDF4EF`, and off-white `#F6F8ED`. Dark pages use `#9ACBAD` for readable accents on `#1C2D24`.
- Typography: the native Harness application font, with a medium-weight text wordmark.

The native UI plugin owns the sidebar wordmark and mark, page accents, and tagline. `pnpm run fieldwork:build` selects the Fieldwork browser title and copies the mark into the generated browser favicons. The source overlay disables the upstream decorative home branding; the Harness layout and controls remain native.

This is a starter identity for the hackathon. Keep the mark simple, preserve readable contrast, and label demonstration data. The mark reuses MIT-licensed DeepSeek Harness artwork; retain the repository license and attribution when distributing it. See the [captured app pages](../screenshots/README.md).
