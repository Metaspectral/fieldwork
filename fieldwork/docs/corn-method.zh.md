# 玉米种子规划方法

[English](corn-method.md) | 中文

首个流程比较农户选择的小面积播种试验与现有做法，保留田块背景、原做法的理由、约束、原始来源、输入证据类别、已接受的版本及带日期的观察。后续版本不会改写此前决定或观察。

## 计算

`corn-seed-budget-v1` 使用公顷表示面积、每英亩种子或植株数量表示密度，并明确每袋粒数、每袋报价以及 CAD 或 USD 币种。一个国际英亩等于 4046.8564224 平方米。

1. 替代播种密度为目标成株密度除以综合成苗比例，再向上取整。
2. 试验面积以外保留原播种密度。
3. 合并所需种子数并向上取整，再按整袋购买。
4. 分别报告原方案及试验方案的采购成本与剩余种子。

综合成苗比例包含发芽及田间损失，不能再次重复扣除发芽损失。农户提供目标及估计比例，应用不会推荐这些数值。计算假设同一可互换种子批次且没有库存。不同品种、包装、价格及现有库存需要单独预算。系统不会据此推荐产量、利润、品种适用性、肥料、农药或灌溉。

[科罗拉多州立大学推广服务](https://extension.colostate.edu/resource/optimizing-corn-plant-population-for-maximum-benefits/)支持按成苗情况调整播种量，并根据田间历史选择估计值。其农艺背景具有地区性，应用不直接采用其种植密度范围。[南达科他州立大学推广服务](https://extension.sdstate.edu/corn-planting-populations-deeper-dive)指出经济播种决策还取决于地区条件、杂交品种、种子成本、预期产量和粮价。采购成本本身不能确定最优方案。

## 证据与审核

输入分为农户报告、实测、地区性、假设、缺失或演示。这些类别表示来源，并非科学认证。实测和地区性输入在接受前需要引用。缺失输入会阻止接受。真实田块不能接受由演示或缺失来源支撑的方案。来源保留原始身份、采集时间、内容哈希、适用范围及准确的单元格、页码或文本块位置。

电子表格保留公式文本及缓存结果，导入不重新计算。HTML 以不可执行文本提取。PDF 按页提取文本，扫描页需要先做 OCR。公开 HTTPS 采集不支持登录页面、任意端口、仅 IPv6 主机或跨源重定向，可改为导入保存的原件。

继承的入门风险规则仍为原型。真实数据模式不展示未经地区验证的分类及水分、土壤流失和肥料成本估算。地区天气摘要采用假定作物日历并明确说明局限。虚构入门模式仍通过 `pretend` 标记演示历史界面。

## 验证

领域测试覆盖面积单位、成苗除法及取整、整袋和余量、非法输入、引用、迁移备份、原件、XLSX 缓存公式、PDF 页码、HTML 脚本排除及不可改写版本。原生组合测试覆盖共享入门修正及拒绝授权。浏览器测试覆盖导入、查看单元格、审核接受方案、添加观察、创建版本及重新加载。

这些检查验证软件计算及已说明的边界。田间建议仍需适合当地的证据及农户判断。手机访问不在本里程碑范围内。
