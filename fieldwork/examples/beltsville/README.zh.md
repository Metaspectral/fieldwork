# Beltsville 公开数据示例

[English](README.md) | 中文

本示例使用 USDA Beltsville 农业研究中心 Central Farm 1-7 的记录。[USDA BARC 归档第 2 版](https://doi.org/10.15482/USDA.ADC/28950746.v2)将数据标为[美国公有领域](https://www.usa.gov/publicdomain/label/1.0/)。包含的三个文件保留下载字节；[manifest.json](manifest.json)记录哈希及来源身份。

## 打开示例

在 **Field learning** 中选择 **Explore Beltsville open data**，审核导入并确认。Fieldwork 创建独立的公开数据田块，编目原件，并保存带有待解问题及本地任务的调查。农场当前做法保持不变。再次打开示例会选择已有调查，不启用监测，也不创建预算或处理试验。

查看关联的[2014 年表格](yield-points-2014.csv)、[已发表产量图](yield-map-2014.jpg)及[管理报告](management-history.pdf)。表格包含 2,984 个清理后的收获监测点。管理报告记载 28.95 英亩，约 11.7156 公顷；其中较晚的青贮玉米及黑麦历史与 2014 年产量观察分开。当前作物、管理、农户理由及权威的当前田块边界仍未知。

选择 **Inspect yield points**，审核 `XCoord`、`YCoord` 和 `YLD_VOL_DR`。已发表地图图例将籽粒产量单位标为 `bu/ac`；除非原始文档支持，否则坐标系标签保持未知。描述性检查保留 2,984 个有效行，无缺失或无效行，未加权点均值约为 117.070 bu/ac。这不是按面积加权的田块产量、诊断或处理比较。已发表插值图与清理后的点属于不同产品，数值范围不同。

## 调查内容

工作问题是：低产条带是否在可比较的玉米季节重复出现，改变做法前应检查什么。审核单位、校准、水分校正、覆盖和机械作业影响；添加匹配季节及管理背景；再记录田间观察和相互竞争的解释。将缺失证据保留为本地任务，农户准备好后才选择替代做法与试验设计。

当前执行器检查点并在导入坐标空间中绘图，不对齐历史栅格、不计算持续性、不诊断板结或排水问题，也不将产量像元当作试验重复。[方法说明](../../methods/historical-yield/SKILL.md)定义调查，[方法指南](../../methods/README.zh.md)描述私有文件和运行行为。
